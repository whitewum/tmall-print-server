# 天猫魔盒 P1007 网络打印服务器

把闲置的安卓电视盒子变成 HP LaserJet P1007 的局域网打印服务器。
手机和平板通过浏览器上传 PDF、JPG、PNG，盒子独立转换并通过 USB 打印，电脑可以关机。
无需 root、Docker 或手机打印 App。

```text
手机／平板浏览器 ──家庭局域网──> 安卓盒子 :8080 ──USB──> HP P1007
电脑（已安装驱动）──────────> 安卓盒子 :9100 ──USB──> HP P1007
```

## 能做什么

- PDF/JPG/PNG，A4 黑白；1–10 份。
- PDF 页码：留空为全部，支持 `2`、`1-3`、`1,3-5` 和中文逗号。
- 单文件最多 20 MB，单任务页数乘份数最多 100，顺序处理最多 5 个活动任务。
- 打印机重启后按状态自动加载 RAM 固件；保存 USB 默认应用授权后可减少重复操作。
- 保存服务启用状态，尝试随盒子开机启动；电脑 RAW 打印支持 Bonjour/DNS-SD 发现。

这不是 AirPrint/IPP 打印机，不会直接出现在 iPhone 系统打印列表里。
Word、Excel、HEIC 请先转为 PDF 或 JPG。电脑 RAW 端口需要驱动生成 P1007 数据，
不能直接向 9100 发送 PDF。

## 已验证的设备

| 部件 | 实测配置 |
| --- | --- |
| 安卓盒子 | 天猫魔盒 M18A，约 1 GB 内存，32 位 ARM 用户空间 |
| 系统 | 原厂固件 6.1.0 系列，Android API 22 |
| 打印机 | HP LaserJet P1007，USB VID:PID `03f0:4817` |
| 客户端 | Mac 电脑打印队列；iPhone 浏览器网页打印 |

应用最低要求 Android 5.0 / API 21，包含 armeabi-v7a 编码器。
只验证了上述硬件；不要把上游编码器支持的打印机列表视为本应用兼容列表。
其他电视盒子需要 USB Host、可运行本地 ARM 程序，并允许应用常驻。

## 开始使用

公开源码不包含 HP 固件、签名私钥或本机 APK。请先按 [构建说明](BUILD.md)
在本机准备固件并生成 `build/P1007Bridge.apk`。目前构建流程在 macOS 上验证。

1. 盒子通过网线或 Wi-Fi 加入家庭局域网，打印机通电并通过 USB 接到盒子。
2. 安装自己构建的 APK：

   ```sh
   adb connect <盒子IP>:5555
   adb install -r build/P1007Bridge.apk
   adb shell am start -n net.local.p1007bridge/.MainActivity
   ```

   有多个 ADB 设备时，在命令中加 `-s <盒子IP>:5555`。
   ADB 网络调试开启方式由盒子固件决定；也可以自行用 U 盘安装 APK。

3. 在显示器上允许应用访问打印机 USB；系统提供选项时，勾选默认/始终使用。
4. 在应用中启用打印服务。若提示缺少固件，检查构建前是否已准备本机固件。
5. 手机浏览器打开应用显示的地址：`http://<盒子IP>:8080`。
6. 上传一页 PDF 验证内容和比例，再测试指定 PDF 页码。常规打印不需要 ADB 或 Mac 在线。

例如盒子地址为 `192.168.1.100`，网址就是 `http://192.168.1.100:8080`。
该 IP 仅作示例，必须替换为自己设备的实际地址。
HDMI 与遥控器主要用于首次安装、USB 授权和故障处理。

## 网络、重启与故障排查

建议在 DHCP 服务器为盒子有线网卡保留地址。使用 WDS/无线桥接时，上游路由器
可能把下游设备映射到桥接 MAC，不能仅凭设备列表里的 IP 就封禁该条目。
详见 [固定 IP 与断电恢复](docs/network-and-recovery.md)。

打印网页仅面向可信家庭局域网。8080 的页面令牌用于 CSRF 防护，不是用户登录认证；
同一局域网设备可打开页面并提交任务。RAW 9100 也没有用户认证。
不要配置公网端口转发，也不要向不可信访客网络开放服务。

开机启动与打印机单独断电恢复已做过实测；盒子厂商仍可能限制自启动或 USB 授权。
**低内存清理、长期闲置及不同固件上的常驻可靠性尚未充分验证。**
测试期间原厂应用造成的内存压力曾导致包括打印服务在内的进程被清理，
打印服务随后恢复；不能据此承诺永不中断。
打印中断不会自动重放或续打，请检查已出纸的页码后重新提交。
“已发送”只表示数据已交给 USB 工作者，实际结果以纸张输出为准。
