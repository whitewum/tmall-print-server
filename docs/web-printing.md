# 手机和平板网页打印

在同一家庭局域网里，用 Safari、Chrome 或其他现代浏览器打开：

`http://192.168.1.100:8080`

点“选择文件”，选 PDF、JPG 或 PNG，设定页码和份数后点“提交打印”。
iPhone 的文件菜单可选照片图库或“选择文件”；无需安装打印 App。
魔盒完成文档渲染、P1007 编码和 USB 发送，Mac 不参与文档处理。

当前能力：

- A4、黑白、1–10 份。PDF 可选择页码；图片按单页打印。
- 页码留空打印全部；可填 `2`、`1-3`、`1,3-5`，也支持中文逗号。
- 重复页码会去重；越界或倒序区间会提示错误。
- 单文件不超过 20MB；单任务的页数乘份数不超过 100。
- 最多 5 个活动任务，顺序处理，展示最近 20 条任务记录。
- “已发送”代表 USB 工作者确认已传输，纸张输出仍以打印机为准。
- 任务成功或失败后删除原文件及生成的打印数据；任务记录在内存中。
- 重启不重放上次的打印任务，避免重复出纸。
- 不支持 Word、Excel、HEIC 或加密 PDF。可先导出 PDF/JPG。
- 这不是 AirPrint；仍需在网页选取文件。

上面 IP 只是示例。请使用魔盒界面显示的实际地址；地址变化后需更新书签。
建议在负责 DHCP 的路由器里为魔盒设置地址保留，详见 [固定 IP 与断电恢复指南](network-and-recovery.md)。
网页只接受数值局域网 IP Host，不接受任意域名。
网页监听 8080，原有电脑 RAW 打印仍监听 9100，并共用同一串行 USB 工作者。

## 实现与构建

`PdfRenderer` 分块渲染 PDF；图片使用 Android Bitmap 解码和 EXIF 方向。
页面转换为 1200×600 采样的黑白 PBM，由 OpenPrinting `foo2xqx` 编码。
P1007 的上游配置使用 1200×600（2 bit video mode），横向坐标按两倍采样率补偿；
不能直接用首版的通用 600×600 模式，该模式实机出现基本空白页。

渲染过程中每次只保留 128 行，避免一次分配整张高分辨率 A4 图像。
转换器是 Android API 21 / armeabi-v7a PIE 可执行程序，由应用沙箱内运行，无 root。
使用 Android NDK r26d：

```sh
python3 tools/build_native.py
python3 tools/prepare_firmware.py
python3 tools/build.py
```

`native/upstream` 保留完整所需源码与原许可证。固件、签名密钥、SDK/NDK
及编译产物仅保存在本机，不进入 Git。

## 常驻和限制

原厂系统禁止 ADB shell 写入受保护的休眠设置；修改该设置的尝试没有生效。
服务使用应用自己的屏幕级保持唤醒锁防止盒子闲置待机，停止服务时释放。
显示器可单独关闭或切换输入。没有更改受保护的系统设置。
本机重启后已确认服务和 USB 授权恢复；该轮重启后的实际出纸尚未额外验证。
长时间闲置、网线重连以及路由器/桥接设备重启的恢复仍需持续实测。
