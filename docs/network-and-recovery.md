# 固定 IP 与断电恢复指南

适用方案：天猫魔盒通过网线连接家庭网络，USB 连接 HP LaserJet P1007，
手机、平板通过浏览器上传文件打印。无需 root、Docker，也不需要 Mac 常开。
已验证的设备是天猫魔盒 M18A（Android 5.1.1）；其他型号需自行验证。

## 1. 为什么要固定 IP

魔盒默认通过 DHCP 自动获取地址。重启后可能仍是原地址，但不能保证一直不变。
网页打印需要访问魔盒 IP，因此建议在负责分配地址的路由器上设置 **DHCP 地址保留**。
设置后魔盒继续自动获取网络配置，路由器会把指定 IP 分配给同一块网卡。

网络拓扑示例（请按自己家里的网络替换）：

```text
小米主路由（192.168.1.1，负责 DHCP）
  └─ 无线桥接 → FAST 路由器
                  └─ 网线 → 天猫魔盒（示例 192.168.1.100）
                               └─ USB → HP P1007
手机／平板连接同一家庭局域网
```

这些地址只是示例，不要直接套用到其他网段。FAST 在此作为无线桥接设备，
地址保留应在上游小米设置。如果下游路由器实际工作在路由/NAT 模式并自行分配地址，
则应在下游 DHCP 服务器设置；同时需检查手机与魔盒是否能够互相访问。

## 2. 在小米路由器保留地址（推荐）

不同型号和固件的菜单名称可能不同，以下是通用流程，并非所有型号都有相同菜单。

1. 保持魔盒的网线连接，在路由器管理页登录。示例为 `http://192.168.1.1`；
   如果打不开，请查看手机当前 Wi-Fi 的“路由器”地址。
2. 在“已连接设备”中找到魔盒。设备可能显示为天猫魔盒、MagicBox 或未知设备。
   对照当前 IP 和魔盒网络设置确认身份。
3. 记录魔盒 **有线网卡的 MAC 地址**。有线与 Wi-Fi 的 MAC 不同，当前用网线就绑定有线 MAC。
4. 找到“局域网设置 / DHCP / 静态地址分配 / 地址保留”等入口，
   选择该设备，保留它当前使用的地址，例如 `192.168.1.100`。
5. 保存。如果路由器提示地址必须在特定范围内，遵循该路由器的要求；
   确保该地址未被其他设备使用。
6. 魔盒继续使用“自动获取 IP”，不需要再在魔盒里手填静态 IP。
7. 空闲时重启魔盒或重新连接网线，查看其地址是否仍为保留值。
8. 手机打开 `http://192.168.1.100:8080`，确认网页显示“打印机已连接”，
   再提交一页文件验证实际出纸。

“IP 与 MAC 绑定”有时只表示 ARP 安全绑定，不一定会保留 DHCP 地址。
如果菜单名称如此，请查看说明，确认它具有固定 DHCP 分配的功能。

## 3. 路由器没有地址保留功能怎么办

可在魔盒的有线网络设置里手动填写静态 IP，前提是原厂系统提供该选项。
先记录当前自动获取的 IP、子网掩码、网关和 DNS，再配置：

- IP：与家庭局域网同一网段，且无人使用的地址。
- 子网掩码、网关、DNS：按当前网络的实际配置填写。
- 所选 IP 应在 DHCP 自动分配池之外，或先在路由器中将其排除，防止地址冲突。

不要只凭示例猜测掩码或 DNS，也不要随意占用 DHCP 池中的地址。
没有手动设置入口时，可继续使用自动获取；地址变化后，查看魔盒打印应用显示的新地址。

## 4. 日常使用与断电恢复

手机、平板直接访问 `http://<魔盒IP>:8080`。可把地址加入书签或主屏幕，
其他家庭成员使用同一地址，不需要安装打印 App。这是网页打印，不是系统 AirPrint。

- 魔盒、打印机、路由器及桥接设备需要通电；魔盒网线和打印机 USB 需要连接。
- HDMI 和遥控器主要用于初次配置或处理系统授权；显示器可关闭或切换输入。
- 打印应用启用后会保存状态，并尝试在开机时启动服务。
- USB 首次授权时，确认使用此应用，并选择系统提供的默认/始终使用选项。
- 打印机重启后需要重新加载内存固件，应用会在识别缺少固件时自动处理。
- 断电时未完成的任务不会续打或自动重放；检查已经出纸的页码后，手动重新提交剩余页。
- 网页最近任务记录只存在内存中，服务重启后清空。

## 5. 如何验收自动恢复

在没有打印任务时操作：

1. 拔掉魔盒电源，等待约 10 秒，重新插入。
2. 不手动打开打印应用，等待约 1～2 分钟；原厂启动较慢时可再等一会儿。
3. 手机访问原网页地址，确认服务可用、打印机已连接。
4. 提交一页小文件，确认内容和比例正确。
5. 后续分别检查打印机断电再开、网线拔插、路由器/桥接设备重启，
   最后观察隔夜闲置后的可用性。不要在打印过程中拔线测试。

本项目当前实测：魔盒重启已确认（启动 ID 改变），原 IP 的网页恢复，
打印服务与 USB 授权均存在；该轮尚未额外确认重启后的实际出纸。
打印机单独断电再开后的固件加载和出纸此前已验证。
长时间闲置、路由器/桥接设备重启、DHCP 地址变化仍需验证。
详细记录见 [实机验证记录](verification.md)。

## 6. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 网页打不开 | 确认魔盒已开机、网线已接好、手机在同一局域网；查看魔盒当前 IP，并使用 `http://` 和端口 `8080` |
| 原 IP 失效 | 查看路由器设备列表，确认地址保留及有线 MAC 是否正确；更换为 Wi-Fi 后需要重新绑定对应网卡 |
| 网页正常，但提示打印机未连接/未授权 | 检查打印机电源、USB；接上显示器查看授权提示，必要时在应用里重新授权 |
| 显示已发送，却没出纸 | 检查纸张、打印机指示灯和固件状态；“已发送”不等于纸张已经输出 |
| 来电后服务没恢复 | 确认魔盒是否真的自动开机，应用是否启用；检查原厂系统的自启动限制及 USB 授权 |
| 放久后不能访问 | 检查盒子是否进入待机；应用已有保持唤醒锁，但原厂系统行为仍需长期观察 |
| 手机与魔盒互相不可达 | 检查访客 Wi-Fi、AP 隔离、不同子网或下游路由/NAT 配置 |

固定 IP 只能稳定地址，不能解决设备未开机、USB 未授权或网络隔离问题。
无需配置公网端口转发，也不要把打印端口映射到互联网。

## WDS 桥接与仅限内网使用

WDS/无线桥接可能改写下游设备的 MAC；上游显示的 IP 不一定能唯一标识一个设备。
设置地址保留或访问限制前，核对盒子有线 MAC；如果关闭一条记录影响多台设备，
立即恢复原规则，不要封禁整个桥接设备。

打印本身无需互联网。若要固定固件版本，应使用可靠的单设备外网限制并验证 LAN 仍可访问。
已经下载的更新不会因断网而撤销，断网也不会停止厂商后台程序。
不推荐给普通用户随意填写不存在的网关：它可能后来被其他设备占用，
且 IPv6/Wi-Fi 等其他通路也需单独检查。
